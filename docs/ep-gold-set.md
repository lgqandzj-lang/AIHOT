# 金标

日期：2026-10-02。阶段 3 尚未完成。

可检查的候选名单是 `docs/gold/varipulse-candidates.json`。2026-10-02 用 PubMed 检索 `VARIPULSE[Title]`，返回 15 条。13 条是电生理研究候选。PMID `3736805` 是 1986 年的二氧化碳激光，PMID `39702987` 是勘误，两条都排除，不能填计数。

`counts` 仍是空的。模型输出、中文解读和助手对照不能写入 `counts`。一条金标计数要同时有材料范围、组别、数量、单位、纳入口径、出处短语和人的署名。署名不能是模型或 agent。材料只限摘要，或文章自身标明 CC BY 4.0 的全文。

`proposals` 是同一天从 PubMed 摘要摘出的待核对计数。只保留摘要原文写明的整数、单位和人群。没有摘要、没有本篇入组整数，或数字来自摘要里引用的别的研究，就不写提案。提案不增加已署名篇数。百分比没有单独给出整数时不反算。操作时间、成功率和并发症不放进这张计数表。
